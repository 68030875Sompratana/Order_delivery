## 2. พจนานุกรมข้อมูล (Data Dictionary) ของ `Order_delivery.csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 100,002 แถว × 23 คอลัมน์
2 คอลัมน์หลักมาใช้วิเคราะห์ ได้แก่ Quantity , Total_Price
 ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | ---: |
| `Quantity` | ตัวเลข | จำนวนสินค้าต่อคำสั่งซื้อ / 1 - 5 ชิ้น (ประกอบด้วยค่า 1, 2, 3, 4 และ 5) หน่วยเป็น ชิ้น | 0 |
| `Total_Price`| ตัวเลข | ราคารวมทั้งหมดของคำสั่งซื้อ หน่วยเป็น บาท | 0 |

หมายเหตุ ข้อมูลชุดนี้ผ่านการทำความสะอาดแล้ว โดยลบแถวที่มีข้อมูลซ้ำและข้อมูลสูญหายออกจำนวน 0 แถว
